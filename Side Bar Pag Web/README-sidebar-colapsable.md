# Sidebar colapsable

Menú lateral de navegación que se puede abrir y cerrar, sin usar JavaScript.

## Qué practica

- **Checkbox hack**: un `<input type="checkbox">` oculto controla, mediante el selector `:checked ~`, si el sidebar está expandido o colapsado — todo sin una línea de JS.
- Iconos de Google Material Symbols para notificaciones, mensajes, carrito, etc.
- `<picture>` + `<../source media="...">` para servir una imagen de perfil más pequeña en pantallas angostas.

## Cómo verlo

Abre `index.html` en el navegador.
