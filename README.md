# HTML & CSS (proyectos de curso)

Colección de ejemplos y pequeñas páginas estáticas creadas durante un curso de HTML y CSS. Cada demo es autocontenida (HTML + CSS, sin JavaScript) y sirve como plantilla o patrón visual para prácticas: componentes UI (caja de chat), layouts (sidebars, flexbox, grid), animaciones y una tarjeta giratoria responsiva.

## Qué hay en este repositorio
- Demo: Caja de chats — componente de chat con burbujas y área de entrada.
  - Ruta: `Caja de chats/index.html` + `Caja de chats/style.css`
- Demo: Página animada (perfil / portafolio) — one‑page con secciones, formulario y animaciones.
  - Ruta: `Pag web ejemplo(animada)/index.html` + `Pag web ejemplo(animada)/style.css`
- Demo: Página con sidebars usando Flexbox.
  - Ruta: `Pagina con sidebars Flexbox/index.html` + `Pagina con sidebars Flexbox/style.css`
- Demo: Tarjeta giratoria responsiva (carpeta `Tarjeta giratoria responsibe/`)
- Activos: imágenes e iconos en la raíz (`icono.png`, `FotosensorArduino.png`, `Protoboard_circuito_multivibradores.jpg`, ...)
