# Página con sidebars (Flexbox)

Ejercicio de layout clásico: navbar superior, sidebar izquierda, contenido central y sidebar derecha.

## Qué practica

- `display: flex` para el layout de tres columnas (`.main-wraper`).
- Anchos fijos en los sidebars y `flex: 1` en el contenido central para que ocupe el espacio restante.
- Estructura semántica con `<header>`, `<aside>`, `<main>`, `<footer>`.

## Cómo verlo

Abre `index.html` en el navegador.
